Cấu hình env, restart và máy thứ hai

.env.local chứa PORT và Turso URL/token. Wrapper scripts/run-next.mjs nạp file bằng dotenv trước CLI Next; biến đã export trong shell ưu tiên hơn file. Đổi cấu hình cần restart. Máy thứ hai dùng cùng Turso URL/token, nhưng phải kiểm registry/port của máy đó. Không có offline sync.

Proxy và phạm vi bind thực tế

App bind 127.0.0.1. Proxy đang publish 0.0.0.0:80, rộng hơn loopback của app; bootstrap không đổi publication. Route nằm trong managed section của Caddyfile, được validate trước restart riêng container dev-hub-caddy vì admin API tắt. Không sửa hosts hoặc cài system service. URL trực tiếp hoạt động khi proxy dừng.

allowedDevOrigins chỉ thêm intelligence.localhost cho asset/HMR dev. Import API giữ same-origin Host check, không mở CORS.
